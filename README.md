# Mainspring for Umbrel

A community app store with one app: [Mainspring](https://github.com/kacperkwapisz/mainspring).

## Install

1. On your Umbrel, open **App Store**, then the **⋯** menu, then **Community App Stores**.
2. Paste `https://github.com/kacperkwapisz/mainspring-umbrel` and choose **Add**.
3. Open **Mainspring** from the new store and choose **Install**.

Open it from the Umbrel dashboard. Umbrel's login protects the panel. The API at
`http://umbrel.local:8317/v1` answers to the `sk-ms-` keys you create in the panel.

See the [Mainspring README](https://github.com/kacperkwapisz/mainspring#readme) for
connecting Claude Code, Codex and other tools.
